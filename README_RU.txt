ҲАМНАФАС — сайт-инструкция (обновлённая версия)

ВАЖНО: первый файл в корне — index.html. ZIP распаковать перед загрузкой на GitHub.

Состав:
- index.html — сайт (динамически получает конфигурацию из config.js)
- config.js — ВСЕ основные тексты, заголовки, ссылка нижней кнопки, шаги
- screenshots/01.png … 06.png — прежние скриншоты
- screenshots/07.png … 11.png — пять новых скриншотов
- screenshots/app-preview.webp — финальный блок приложения

Чтобы изменить текст:
1. Откройте config.js в редакторе.
2. Найдите нужный объект внутри массива "steps".
3. Замените "title" (заголовок) и "text" (описание).
4. Следите за кавычками, запятыми и фигурными скобками. Если нужно слово в кавычках, используйте «ёлочки», а не ".

Чтобы добавить шаг:
1. Положите картинку в screenshots/ под новым именем, например 12.png.
2. Скопируйте предыдущий объект шага в массиве "steps" в config.js.
3. Измените title, text и image на screenshots/12.png.
4. Проверьте запятую между объектами.

Чтобы удалить шаг: удалите объект шага из массива "steps" вместе с нужной запятой.
Порядок объектов — порядок карточек на сайте. Нумерация автоматическая.

Кнопка перехода: измените параметр "nextUrl" в config.js.
После изменения в GitHub нажмите Commit changes. Сайт обновится после публикации;
браузер может требовать Ctrl+Shift+R для сброса кэша.

ИЗОБРАЖЕНИЯ: эти макеты — иллюстрации. Внешний вид Android, Google Play и запросов
разрешений может отличаться. Не рекомендуется разрешать VPN или установку из неизвестных
источников без проверки безопасности приложения и понимания запрашиваемых прав.
